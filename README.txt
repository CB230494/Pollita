PARA KENIA — JUEGO ROMÁNTICO PARA GITHUB PAGES

CONTENIDO
- index.html: página principal y carta de amor.
- styles.css: diseño adaptable a teléfonos y computadoras.
- script.js: animación, botón Sí evasivo, carta, corazones.

PUBLICAR EN GITHUB PAGES
1. Crea un repositorio público en GitHub (por ejemplo: Para-Kenia).
2. Descomprime el ZIP y sube index.html, styles.css y script.js a la RAÍZ del repositorio.
3. En Settings > Pages > Build and deployment selecciona Deploy from a branch.
4. Elige main y /(root), y guarda.
5. Abre la URL que GitHub Pages muestre al terminar la publicación.

PERSONALIZAR LA CARTA
Abre index.html en un editor y modifica únicamente los párrafos dentro de la sección con class="letter".
No requiere base de datos, npm ni claves. Utiliza Google Fonts; si no hay internet, muestra fuentes alternativas.
